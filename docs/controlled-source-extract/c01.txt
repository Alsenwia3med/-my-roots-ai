FINAL CONTROL SHEET
This sheet replaces the prior v1.0.1 correction cover. The attached legacy human-readable pages are retained only for source
provenance. Where they display v1.0.0 metadata or superseded fields, this sheet and the matching v1.0.1 executable XLSX control.
1. Canonical version metadata
questionnaire_version is 1.0.1 for all 73 question records. README title/version, Modules version statement and implementation
publication sequence are v1.0.1. Scoring source is C-02 v1.0.1.
2. Required multi-select validation
Q13, Q14, Q52, Q53 and Q54 require one or more approved option IDs. An empty array is invalid. NONE/N/A is exclusive where
such an option is provided.
3. Q73
Q73 remains optional free text and allow_na = FALSE. A blank optional Q73 remains blank; the system must not invent an N/A
response.
4. Required-response rule
Required = valid response or explicit approved N/A where the canonical question permits N/A. Optional questions may remain blank.
Missing is not inferred as N/A.
5. Executable authority
The matching file 02_ROOTS_AI_C01_Canonical_Question_Bank_v1.0.1_CORRECTED.xlsx is the authoritative executable
dataset. Exact package SHA-256 is controlled by the final reference register and SHA256SUMS.txt.
6. Precedence
This v1.0.1 final control sheet supersedes all v1.0.0 version labels and the specifically corrected validation fields in the attached
legacy pages. It does not alter the approved 73-question wording/order, 13-module structure, scoring eligibility or other unaffected
canonical content.
